# 平台链接判断

## 具体商品页

示例特征：

- `/item/...`
- `/product/...`
- `/goods/...`
- 查询参数含 `goods_key`、`product_id`、`sku`

用途：

- 识别平台和店铺；
- 识别具体商品；
- 读取公开价格、标题和商品类型；
- 建立应用商品映射。

优先请求此类链接。

## 收银台或支付页

示例特征：

- `/pay...`
- `/cashier...`
- `/checkout...`
- `/order/result/...`
- 查询参数含临时 `trade_no`、`order_no`

用途：

- 识别支付渠道；
- 判断是否能内嵌；
- 分析下单、查单、回调或支付完成路径。

限制：

- 临时订单号不能建立商品映射；
- 链接可能过期；
- 不能把单个支付链接当成平台长期契约。

## 平台首页或店铺页

用途：

- 识别平台和店铺；
- 寻找商品列表。

限制：

- 通常无法知道具体商品；
- 若没有适配器，需要具体商品页或商品后台截图。

## 信息不足时的回复

直接说明：

```text
这个链接可以识别平台，但无法确定具体商品。
请再提供一个具体商品页链接；
如果没有公开链接，提供商品后台截图也可以。
```
