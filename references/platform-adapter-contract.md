# 卡密平台适配器契约

平台适配器只处理协议差异，不处理商品设计、库存或商业模式。

## 必需能力

### listProducts

输入：平台商品链接、后台截图或适配器配置。

输出：

- 平台商品 ID；
- 商品名称；
- 价格；
- 商品类型；
- 可选库存状态。

### createOrder

输入：

- 平台商品 ID；
- 应用用户稳定标识；
- 可选查询口令。

输出：

- 平台订单号；
- 收银台地址；
- 应付金额；
- 过期时间。

### queryPayment

输入：平台订单号。

输出：未支付、已支付、关闭、未知，或可重试错误。

### fetchCards

输入：平台订单号和查询凭据。

输出：卡密数组；卡密不得写入普通日志或返回浏览器。

### validatePayUrl

- 只允许 HTTPS（测试环境可按配置放宽）；
- 只允许平台主域或明确白名单；
- 拒绝危险协议和外域页面。

## 通用要求

- 服务端保存平台订单号；
- 查询超时和有限重试；
- 错误分类为可重试、业务失败和人工处理；
- 不在前端暴露平台密钥；
- 不把卡密写入事件表或日志；
- 平台金额、商品映射与应用订单不一致时拒绝自动结算。

## 适配器注册

每个平台一个独立模块，核心工作流不得写死平台域名、商品 ID 或接口路径。

推荐配置：

```yaml
platform: example
enabled: true
base_url: https://example.com
product_url_pattern: /item/{goods_key}
credential_env: CARD_PLATFORM_TOKEN
```
