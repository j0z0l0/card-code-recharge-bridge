# Security Policy

## Supported version

Security fixes are applied to the latest release in the default branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting / Security Advisory feature for this repository. Do not open a public Issue containing:

- API keys, platform tokens, signing secrets or passwords;
- card codes, order exports or customer data;
- production URLs that expose private credentials;
- database connection strings or environment files.

If private reporting is unavailable, contact the project through the website listed in `README.md` and ask for a secure reporting channel first.

## Scope

This repository contains skill instructions, helper scripts and documentation. It does not operate a payment platform, card inventory or hosted service.

Reports about a third-party card platform's availability, account controls, pricing or terms should be handled directly with that provider. Reports about a user's deployed application should be directed to that application's operator.

## Disclosure

Please allow reasonable time to investigate and publish a fix before public disclosure. No fixed response-time guarantee is provided for this open-source project.
